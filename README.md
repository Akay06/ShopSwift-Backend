# 🛒 E-Commerce Website (ShopSwift) Backend

Backend built using **Spring Boot** for the **ShopSwift** E-Commerce website. This service handles user authentication, product management, orders, and transactions.

---

## 📋 Requirements

- **Java 17**
- **Maven**

---

## 🚀 How to Run

### Option 1: Run as a Spring Boot Application 

#### 1️⃣ Navigate to the source folder.  
#### 2️⃣ Run the project using your IDE as a **Spring Boot App**.  

### Option 2: Run via Command Line  

#### 1️⃣ Open a terminal and navigate to the project root directory.  
#### 2️⃣ Build the package using:  
   ```bash
   mvn package
   ```
#### 3️⃣ Run the generated JAR file from the target folder:   
   ```bash
   java -jar target/shopswift-0.0.1-SNAPSHOT.jar
   ```
